Welcome to the CubeCOS Community repo! Here you will find all things community, including our meeting records, resources, upcoming events, and more.

## Getting started

Check out our CubeCOS user guide for introduction of the architecture, quick start guides, release notes, and detailed operating manual.

- To get involved with the project, check out our [contributor guide](https://github.com/bigstack-oss/community?tab=contributing-ov-file).
- We follow the Code of Conduct adopted from Contributor Covenant to ensure a respectful and inclusive environment for all community members. You can find the [Code of Conduct here](https://github.com/bigstack-oss/community?tab=coc-ov-file).
